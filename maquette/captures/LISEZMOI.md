# Captures de la maquette

Exports PNG pleine page, générés depuis les fichiers `.dc.html` de ce dossier (version 2.0).

- Écrans : trois largeurs, `-1440.png` (bureau), `-1024.png` (tablette / petit portable), `-390.png` (mobile).
- Composants (`composants/`) : à la largeur de leur aperçu. `Bibliotheque-1440.png` est le catalogue complet, `Composants-1440.png` les fondations (couleurs, typographie, espacements).
- États IA supplémentaires : `recouvrement/Telephonie-apres-appel-1440.png` (résumé et qualification proposés après l'appel), `administration/Reglages-assistant-ia-1440.png` (section Assistant IA).
- États montrés : données chargées, état par défaut de chaque écran. Les autres états (vide, erreur, confirmations, mode sombre…) se lisent dans le code (`renderVals()`).
- Le logo de la page de connexion est une image hébergée par l'outil de maquette : il n'apparaît pas hors ligne. Les logos officiels sont sur media.legarec.fr.
