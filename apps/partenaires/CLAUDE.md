# apps/partenaires

partenaires.legarec.fr — portail créanciers. Ambiance aérée, titres Lora. Écrans : Connexion (portail partenaires), Portail, dépôt de créances par fichier, accord du créancier sur les échéanciers au-delà du seuil (à proposer). Un créancier ne voit que ses propres dossiers (filtrage par l'API).

- Règles : `.claude/rules/front.md` (chargées automatiquement) ; composants uniquement via `packages/ui`.
- Routes et captures de référence : `scripts/ecrans.json`, `maquette/captures/`.
- Données simulées (MSW) : `maquette/donnees-demo/<Ecran>.json`.
